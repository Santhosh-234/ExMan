# ExMan (Android expense tracker) — project state

Privacy-first, offline-first expense manager. Expo SDK 58 + Expo Router, NativeWind v4 (Tailwind v3), expo-sqlite, lucide icons, react-native-svg for charts (victory-native deliberately skipped: needs Skia). Sideloaded APK, no Play Store. See AGENTS.md for Expo doc-lookup rules.

## Done
- Step 1: skeleton, NativeWind, 4 tabs, schema (`src/db/schema.ts`, versioned migrations, amounts in integer paise), parser + tests (`src/utils/parser.ts`, `npm test`).
- Step 2: native Kotlin module `modules/vibe-listener` (SMS BroadcastReceiver + NotificationListenerService for GPay/PhonePe/Paytm -> SharedPreferences queue). JS drains in `src/ingest/` (parse -> `isDuplicate` 60s check -> insert as `pending`). Settings tab has the permission buttons.
- Verified on a real phone: a bank SMS lands in the Inbox correctly. Notification path (GPay/PhonePe/Paytm) NOT yet verified; notification regexes are guesses.
- CI: `.github/workflows/build-apk.yml` builds an arm64-only release APK to GitHub Releases (~30 min; slow). Release is signed with the debug keystore.
- Step 3 (written, untested on device): real Inbox (swipe confirm/dismiss, edit modal, auto-category via `src/utils/categorize.ts`), Dashboard (month nav, budget bar, SVG donut, filters, insights), Analytics (6-month bars, top merchants), Settings sync (`src/sync.ts`, custom REST or Firefly III). Indian Bank (`VM-INDBNK-S`) added to BANKS; migration 3 backfills old rows.

## Working notes
- Android 13+: sideloaded apps need "Allow restricted settings" before Notification Access can be enabled.
- Native Kotlin was never compiled locally on the Mac (no JDK); CI was the first compile. `android/` is generated by `expo prebuild` and gitignored.
- Fast loop: `npx expo run:android` with the phone on USB (needs JDK 17 + Android SDK/NDK), JS changes hot reload; Kotlin changes rebuild incrementally. Use `adb logcat` to debug the receiver/listener.
- On Windows keep the repo path short and enable long paths (RN native builds hit the 260-char limit).
- Case-insensitive filesystem trap: don't create files differing only by case (`ingest.ts` vs `Ingest.tsx` broke tsc once).
